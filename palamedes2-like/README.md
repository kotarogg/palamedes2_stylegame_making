# palamedes2-like 対戦検証版 v0.2.0（2026-10-18）

パラメデス２風の、640×360・16bit風のブラウザ対戦パズルです。
2026-10-18 に受領した仕様確認への回答（攻撃量・消去・相殺・勝敗・試合進行・入力機器・CPU・役成立光 v2.1）を反映しました。
1ラウンドの対戦から先取制の試合まで、ひととおり遊べる状態です。素材は納品済みの仮スプライトシート7枚（マニフェスト v2.1）です。

> 確定事項と実装・テストの対応表、および反映時に見つかった矛盾・要確認事項は `docs/SPEC_DECISIONS_20261018.md` にまとめています。
> 仕様に記載がなく暫定で決めた扱いは、下の「暫定の扱い」とゲーム中の F1（操作説明）に明示しています。

## 動作環境

| 項目 | 内容 |
|---|---|
| 実行 | Chromium系（Chrome/Edge）・Firefox の最新版を想定。ローカルHTTPサーバー経由で開く |
| 開発 | Node.js 22.12 以上（Vitest 5 の要件。検証は 22.22.0）、npm 10 系（検証は 10.9.4） |
| OS | Windows を基本想定。npm スクリプトはOS依存のシェル構文を使っていない（検証はLinux上で実施） |
| 入力 | キーボード、ゲームパッド（ブラウザの Gamepad API・標準マッピング） |

## セットアップと起動（開発用）

```bash
cd palamedes2-like
npm ci                # package-lock.json どおりに依存を導入
npm run dev           # 開発サーバー http://127.0.0.1:5173/  （停止: Ctrl+C）
```

| コマンド | 内容 |
|---|---|
| `npm run typecheck` | TypeScript 型検査（tsc --noEmit） |
| `npm test` | 自動テスト（Vitest：ロジック・役判定・入力・CPU・表示計算・データ 114件） |
| `npm run build` | 型検査＋本番ビルド → `dist/` |
| `npm run preview` | ビルド結果を http://127.0.0.1:4173/ で確認 |
| `npm run serve:dist` | 依存なしサーバーで `dist/` を http://127.0.0.1:8080/ に配信 |
| `npm run e2e` | ブラウザ実機確認（要ビルド済み dist、Chromium）。結果は `test-results/e2e/` |
| `npm run verify` | 型検査→テスト→ビルド→ブラウザ確認を一括実行 |

ブラウザ確認（e2e）は `playwright-core` を使います。Chromium が無い環境では、一度だけ
`npx playwright-core install chromium` を実行してください。

## ビルド済み実行版の起動

`dist/`（配布ZIP・共有フォルダではプレイ版フォルダ）を HTTP で配信して開きます。HTMLをダブルクリックして開く方法（file://）では、
ブラウザが素材のJSON読込を拒否するため動きません。

- Windows：`start-windows.bat` をダブルクリック → ブラウザで http://127.0.0.1:8080/ を開く（Node.js が必要）
- 共通：`node serve.mjs . 8080`（停止は Ctrl+C）
- Node.js が無い場合：Python があれば `python -m http.server 8080 --bind 127.0.0.1`

URL に `?seed=数値` を付けると、同じ乱数列（初期盤面・生成ピース）で再現できます。

## 操作（初期割当。F2 の設定画面で変更可能）

| 操作 | 1P | 2P | ゲームパッド |
|---|---|---|---|
| 左右移動 | A／D | ←／→ | 十字キー・左スティック |
| 発射 | F | , | A |
| B入れ替え | G | . | B |
| 役宣言 | H | / | X |
| 手動上昇 | W | ↑ | RB |
| 一時停止 | Esc（共通） | Esc（共通） | START |

- 勝敗表示の後は、Enter・Space・各自の発射キー・Ⓐのいずれかで次へ進みます（表示から0.8秒後に受付）
- F1：操作説明・ルール要約・暫定の扱い　F2：設定　R：新しい試合　M：消音　V：素材確認画面（←→でページ切替）
- 検証用の攻撃注入：1／2＝1Pへ+1／+10、9／0＝2Pへ+10／+1（待機攻撃ストックへ直接加算）
- 割り当て済みのキーは、共通ショートカット（R・M・V・数字）より優先します

### 設定画面（F2）

先取本数（1・2・3本、初期値2）、自然上昇の難易度（初級7秒・中級5秒・上級3秒）、各プレイヤーの使用機器
（キーボード／ゲームパッド1〜4／CPU 初級・中級・上級）、キー割当、ゲームパッド割当を変更できます。
設定はこのブラウザに保存されます（保存できない環境では初期値で動きます）。設定画面の操作はキーボードで行います。

## 実装内容

- ロジック（`src/core`、表示に依存しない・固定ステップ60tick/秒）
  - 打ち上げ：到達時判定（数字一致・隣接（1↔6含む）・属性一致）。同一tickは1P優先。予約空白、失敗時は帰還
  - 操作制限：発射中（＝行きの飛行時間）、上詰め中・B入れ替え中、不成立後0.5秒は、そのプレイヤーの全操作が不可。
    発射処理が終われば、帰還中でも予約のない別列を操作可。左右移動中は1回分の入力を保持（最後の入力で上書き）
  - 役判定：全組合せ評価、6個役優先、同点は数字役の翻数→役一覧の掲載順で自動採択、ストック全体を消費
  - 役処理フェーズ：役名・モーション → 上側から1ラインずつ消去（合計翻数ぶん。盤面が空なら打切り）→ 攻撃計算 → 相殺 → 送信 → 終了
  - 連続取得（受付2秒）・役連鎖（受付8秒）：どちらも自分の成立役の処理中は受付時間を停止
  - 攻撃：max(合計翻数−1,0) × 連続取得の攻撃倍率 → 切捨て → 役連鎖加算（+0〜+4）→ 相殺（攻撃力1で待機2）→ 送信。
    同一tickの双方送信は、相殺計算後にまとめて反映
  - 攻撃波：最初の受信から2秒後、以後2秒間隔、1波最大3ライン、攻撃で6段まで、受信は即加算、適用は自分の役処理終了まで待機
  - 自然上昇（難易度別周期）・手動上昇（7段まで、最低間隔0.2秒の補正）、危険猶予3秒・敗北・引分け
  - 試合：先取本数、勝敗表示 → 決定入力 → READY → GO、引分けは同じラウンドを再試行（`src/core/match.ts`）
- 入力（`src/input`）：キーボード／ゲームパッド（割当変更可）、CPU 3段階（反応時間と判断精度。見える情報だけで判断）
- 表示（`src/view`）
  - 論理640×360、整数倍拡大でドットを滲ませない。マニフェスト v2.1 から切り出し、読み込み許可リスト（7シート）だけを読む
  - 役成立光：採用ピースの連続区間ごとに 1〜6枠用 を配置（対象左上−原点オフセット）。宣言前から発光。A/B各250msの共有時計
  - ライン消去：消える段は元の位置で消滅演出 → 足場・キャラだけが1段ずつTWEEN（残ったピースは動かない）
  - 危険表示・猶予の残り時間、WIN/LOSE/DRAW/RESULT/PAUSE バナー、勝利数、取得倍率、役連鎖ゲージ
  - 素材確認画面（V）：7ページ（役成立光の同期確認ページを追加）
  - 効果音：仮の電子音（音素材は未納品）

## 暫定の扱い（仕様に記載がない／解釈が分かれる箇所。要確認）

| 項目 | 検証版の扱い |
|---|---|
| ストック4個未満での宣言 | 不成立として扱う（0.5秒硬直）。設定で「無視」に切替可 |
| 危険猶予の解除時に保留していた自然上昇 | 解除時に実行（役処理中なら終了後）。設定で破棄に切替可 |
| 左右移動中の手動上昇 | 保持の対象外のため、移動中でも即時実行 |
| 取得倍率パネル | 連続取得の攻撃倍率を表示（得点倍率は表示しない。得点計算なし） |
| 役ストックの描画層 | 背面光55とキャラ60の間（56）に描画（「背面→ピース→前面」を守るため） |
| 不成立モーション・効果音 | 専用素材が無いため、待機枠の揺れと仮の電子音で代用 |
| 勝敗表示後の決定入力 | 人が操作するどちらのプレイヤーでも可。全員CPUなら3秒後に自動で進む |
| 初期値 | 自然上昇は中級（5秒）、1P・2Pともキーボード |

アニメーション時間・CPUの反応時間などの調整値は `src/core/config.ts`（`DEFAULT_CONFIG` / `DEFAULT_VIEW_CONFIG`）と
`src/input/cpu.ts`（`CPU_PROFILES`）に分離しています。いずれもテスト用の初期値です。

## フォルダ構成

```text
palamedes2-like/
  docs/reference/  取得した仕様・JSON/CSVの読取り用コピー（原本は共有Drive）
  docs/            環境記録・技術選定・仕様反映記録・テスト結果・残課題
  public/assets/sprites/  仮PNG7枚（原本のまま、SHA-256照合済み。effects_sheet は v2.1）
  public/data/     sprite_manifest_v2.json（v2.1）/ screen_layout_v2.json / asset_loading_policy.json（原本のまま）
  src/core/        表示非依存のロジック（ルール・盤面・役・攻撃・試合進行・固定ステップ）
  src/input/       キーボード・ゲームパッド・CPU・設定の保存
  src/view/        描画・補間・役成立光・設定画面・効果音・素材確認画面
  tests/           自動テスト
  scripts/         配信サーバー・ブラウザ確認・結果一覧生成
```

画像を差し替えるときは、`public/assets/sprites/*.png` と `public/data/sprite_manifest_v2.json` を差し替えるだけです。ロジックは変更しません。
