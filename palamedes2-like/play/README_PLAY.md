# コタローくんパズル 第3版 v3.2.0（2026-10-27）起動手順・操作説明

タイトル、メインメニュー、MODE1（シングル：ひたすら／ステージクリア、CPU対戦、2P対戦）、MODE2（シングル、CPU対戦、2P対戦）、
オプション（音・操作・対戦・表示・クレジット）、遊び方を収録した版です。
第3版の採用画像（49枚＋v3.1.0追加9枚）・フォント（Noto Sans JP）・BGM・効果音・3キャラクター（コタロー／アカネ／東北ずん子）のボイスを統合しています。

## 必要なもの

- Windows 10／11 の PC
- ブラウザ：Microsoft Edge または Google Chrome の最新版（自動検証は Chromium で実施。Firefox は未検証）
- Node.js 18 以上（LTS 推奨）：https://nodejs.org/
  - ゲームを配信する簡易サーバーに使います。開発用の `npm install` やビルドは不要です
  - お使いの PC に Node.js が入っているかは確認していません。入っていない場合は上記からインストールしてください

## 起動（Windows）

1. このフォルダ一式を PC に保存する（共有ドライブからはフォルダごとダウンロード → ZIP を右クリック「すべて展開」）
2. 展開したフォルダの `start-windows.bat` をダブルクリック
   - 黒いウィンドウが開き、少しして既定のブラウザで `http://127.0.0.1:8080/` が開きます（この URL はご自分の PC の中だけのアドレスです）
   - 「WindowsによってPCが保護されました」と出た場合は「詳細情報」→「実行」
   - ブラウザが自動で開かない場合は、黒いウィンドウに表示された URL を手で開いてください
3. タイトル画面で A／Enter を押すとメインメニューへ（最初の操作で音が出るようになります）
4. 終了：ブラウザのタブを閉じ、黒いウィンドウを閉じる（または Ctrl+C）

### うまく動かないとき

| 症状 | 対処 |
|---|---|
| `index.html` をダブルクリックすると真っ黒・エラー | 直接開く方法（file://）では素材を読めません。必ず `start-windows.bat` から起動してください |
| 「Node.js was not found」 | Node.js をインストールして、もう一度 `start-windows.bat` を実行 |
| ポート 8080 が使用中 | 自動で 8081〜8090 の空き番号を使います。黒いウィンドウに表示された URL を開いてください |
| 画面上部に「採用フォント（Noto Sans JP）を読み込めませんでした」 | `gfx/fonts/NotoSansJP-VF.ttf`（9,590,732 bytes）が欠けています。フォルダを取り直してください |
| 音が出ない | 画面上部に案内が出ている間は、キーを1回押すか画面をクリックする（ブラウザの自動再生制限）。オプション「音」で音量・ミュートも確認 |
| ゲームパッドが反応しない | ブラウザのタブをクリックしてからボタンを1回押す。オプション「操作」で 1P/2P の入力機器をゲームパッドに変更 |
| 画面が小さい／大きい | オプション「表示」の「画面表示倍率」。収まらない倍率は「選択不可」と表示され、選べません |

Node.js が無く Python がある場合は、このフォルダで `python -m http.server 8080 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8080/` を開いても遊べます。

## 操作（初期割当。オプション「操作」で変更可）

| 操作 | 1P キーボード | 2P キーボード | ゲームパッド |
|---|---|---|---|
| 左右移動 | A／D | ←／→ | 十字キー・左スティック |
| 発射 | F | , | A |
| B入れ替え | G | . | B |
| 役宣言 | H | / | X |
| 手動上昇 | W | ↑ | RB |
| 試合をやめる確認 | Esc | Esc | START |

- メニュー：↑↓（十字キー）で選択、Enter／A で決定、Esc／B で戻る（メインメニューの一番上の階層で戻るとタイトルへ）、←→ で値の変更
- キャラクター選択（2P対戦）：各自の左右で選択、発射キー／A で決定、B入れ替えキー／B で自分の決定を取消。同じキャラクターは選べません
- 試合中の Esc／START は「メニューへ戻りますか？」の確認です。**一時停止ではありません**（確認中もゲームは進みます）
- 結果の後：決定（Enter・発射・A）で次へ

## 遊べるモード

| モード | 内容 |
|---|---|
| MODE1 シングル（コタロー） | ひたすら（Lv1〜20）／ステージクリア（全10面） |
| MODE1 CPU対戦 | キャラクター選択（コタロー／アカネ／東北ずん子、初期はコタロー）の後、CPUと対戦。相手は自分以外の2人を「コタロー→アカネ→東北ずん子」の順で繰り返す（「次の相手へ」で交代。キャンセルで「メニューに戻りますか？」） |
| MODE1 2P対戦 | キャラクター選択の後、2人で対戦 |
| MODE2 シングル／CPU対戦／2P対戦 | 場のカードへ出せるピースを打ち上げ、先に盤面を空にする |

記録（シングルのベスト）と設定は、このブラウザ内に保存されます。

## 遊び方・放置デモ（2026-10-26 追加）

- **遊び方**（メインメニュー／オプション）：目次の「操作一覧」「基本操作」「連鎖説明」「役一覧」「MODE1」「MODE2」を選ぶと、実際のゲーム処理で実演します（MODE2は固定の盤面・入力で最後までクリアします）。B／Esc で目次へ、目次で B／Esc を押すと呼び出した画面へ戻ります。実演の最後は「もう一度」「戻る」を選べます。役一覧は左右で1役ずつ切り替えます
- **放置デモ**：タイトル画面で20秒操作しないと始まります（オプション「デモ再生」でも最初から再生）。説明（基本操作→役成立・打上連鎖・役連鎖→ピンチ）→ MODE1 シングル「ひたすら」の自動プレイ → アカネ対ずん子（中級CPU）の対戦 → タイトルへ戻ります
- デモ中はキー・ゲームパッドのボタン／方向・マウスクリックで終了してタイトルへ戻ります（押しっぱなしやスティックの小さな傾きでは終了しません）。終了に使った操作はタイトルの決定になりません
- デモの結果や設定は保存しません。音量・ミュート・表示倍率はオプションの設定どおりです。ブラウザのタブを切り替えるとデモは止まり、戻るとタイトルになります

## v3.2.0 で確認していただきたい点

- 名称「打上連鎖」（旧「連続出し」）。対戦では成功数とヒビだけを表示し、攻撃倍率の見出し・数値は出しません（攻撃の計算は従来どおり）。シングルの得点倍率は表示します
- 移動の先行入力：移動が終わる直前（2tick＝約33ms以内）に押した左右は、次に動けるタイミングで1回だけ実行されます（移動の速さは従来どおり）
- 出せるピースの補助表示：自分の列の一番上で、今の場へ出せるピースを細い枠で囲みます（オプション「表示」の「出せるピースの表示」でオン／オフ。初期はオン）
- MODE2 シングルで場の更新なしにクリアすると「ノーリセットクリア」と表示し、達成回数を記録します（クリアタイムの記録は従来どおり全クリアが対象）
- CPU の判断の間・選び方・失念・7個目の取得判断を変更しました。新規の設定では CPU の強さの初期値は初級です（保存済みの設定はそのまま）
- 対戦の最終結果：勝敗演出の間は中央の「対戦結果」を出さず、演出後の結果画面に表示します
- 文字素材の修正版（2026-10-28 採用）：「打上連鎖」見出し画像、遊び方用の文字画像（追加14字）、GAME OVER などの「M」、役名の不要な点・「スーパーストレートフラッシュ」の字形
- 移動の先行入力の修正：移動が終わる瞬間に離した・逆方向を押した場合、古い予約で動かないようにしました。画面の更新が遅い環境（低fps）でも押した時刻に合わせて受け付けます

## v3.1.0 で確認していただきたい点

- ピンチ（攻撃ピンチ猶予・自然上昇の危険猶予とも4000ms）：到達で警告音1回、1秒ごとに 3→2→1 の数字と countdown 音、4秒で期限判定
- 試合開始前の1秒の待機（その間の操作は試合へ持ち越さない）
- 打ち上げミスの帰還（列の上から戻り位置へ下りる区間が1.6倍）
- 打上連鎖（旧称 連続出し。v3.1.0 時点は成功数と攻撃倍率。ミス1回で数字にヒビ＝連鎖切り予約、もう1回ミスで終了）と役連鎖（連鎖数と攻撃加算）の表示
- 受攻撃ストックの中央配置、日本語の結果見出し（勝利／敗北／引き分け／対戦結果）
- CPU の動き（難易度・キャラクターごとの傾向）。人間向けの難易度としての評価は未実施です
- 通常の攻撃・被攻撃のボイスは鳴りません。役宣言では20%で役名の代わりに攻撃ボイスになります

## 第3版で確認していただきたい点

- 受けた攻撃の処理（2秒後にまとめて処理、0.4秒ごとに1段、3段ごとに小休止、7段でピンチ猶予＝v3.1.0 は4秒）と、ストック表示（上＝処理中、下＝待機中）
- 3キャラクターの全モーション・ボイス、役名の表示とボイスの同期、勝敗演出（敗者の落下→勝者＋ネコタローのクラッカー）
- BGM・効果音・ボイスの聴感と音量バランス（自動検証では聴感を判定していません）
- ゲームパッド実機での全操作（自動検証は模擬入力のみ）
- 画面表示倍率（DPI 125％・150％などの環境を含む）と全画面表示
