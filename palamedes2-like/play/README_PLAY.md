# パラメデス２風 基本動作検証版 v0.1.0（2026-10-18）起動手順・操作説明

**対戦完成版ではありません。** 攻撃量・役宣言による消去・勝敗は仕様未確定のため動作しません。

## 起動

HTMLファイルのダブルクリックでは動きません（ブラウザが素材の読込を拒否するため）。ローカルHTTPサーバーで開いてください。

1. Node.js（18以上、現行LTS推奨）をインストールしておく（https://nodejs.org/）
2. Windows：このフォルダの `start-windows.bat` をダブルクリック
   - ブラウザで http://127.0.0.1:8080/ が開きます（先に開いて読込失敗した場合は再読込）
   - 終了：黒いウィンドウで Ctrl+C、またはウィンドウを閉じる
3. Mac/Linux：`sh start-mac-linux.sh` → ブラウザで http://127.0.0.1:8080/
4. Node.js が無い場合（Python がある場合）：このフォルダで `python -m http.server 8080 --bind 127.0.0.1`

URL に `?seed=数値`（例 http://127.0.0.1:8080/?seed=123）を付けると同じ盤面で再現できます。

## 操作（検証用のテスト設定。正式なキー割当は未確定）

| 操作 | 1P | 2P |
|---|---|---|
| 左右移動 | A / D | ← / → |
| 打ち上げ | W | ↑ |
| B列入れ替え | S | ↓ |
| 役宣言（ストック4個以上） | Q | / またはテンキーEnter |
| 手動上昇 | E | . またはテンキー0 |

- F1 または H：操作説明と「未確定事項の暫定的な扱い」を表示
- R：最初から　P：一時停止　V：素材確認画面（←→でページ切替、Vで戻る）
- 検証用：1/2＝1Pへ攻撃+1/+10、9/0＝2Pへ攻撃+10/+1（攻撃波・攻撃アイコン表示の確認用）
