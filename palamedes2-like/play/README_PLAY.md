# パラメデス２風 対戦検証版 v0.2.0（2026-10-18）起動手順・操作説明

2026-10-18 の仕様確認の回答を反映した版です。消去・攻撃・相殺・勝敗・先取制の試合・CPU・ゲームパッドに対応しています。
素材はすべて仮素材です。

## 起動

HTMLファイルをダブルクリックして開く方法では動きません（ブラウザが素材の読込を拒否するため）。ローカルHTTPサーバーで開いてください。

1. Node.js（18以上、現行LTS推奨）をインストールしておく（https://nodejs.org/）
2. Windows：このフォルダの `start-windows.bat` をダブルクリック
   - ブラウザで http://127.0.0.1:8080/ が開きます（先に開いて読込に失敗した場合は再読込）
   - 終了：黒いウィンドウで Ctrl+C、またはウィンドウを閉じる
3. Mac/Linux：`sh start-mac-linux.sh` → ブラウザで http://127.0.0.1:8080/
4. Node.js が無い場合（Python がある場合）：このフォルダで `python -m http.server 8080 --bind 127.0.0.1`

URL に `?seed=数値`（例 http://127.0.0.1:8080/?seed=123）を付けると、同じ盤面で再現できます。

## 操作（初期割当。F2 の設定画面で変更できます）

| 操作 | 1P | 2P | ゲームパッド |
|---|---|---|---|
| 左右移動 | A／D | ←／→ | 十字キー・左スティック |
| 発射 | F | , | A |
| B入れ替え | G | . | B |
| 役宣言 | H | / | X |
| 手動上昇 | W | ↑ | RB |
| 一時停止 | Esc | Esc | START |

- 勝敗表示の後：Enter・Space・発射キー・Ⓐ で次のラウンドへ
- F1：操作説明・ルール要約　F2：設定（先取本数、自然上昇の難易度、使用機器（キーボード／ゲームパッド／CPU）、割当）
- R：新しい試合　M：消音　V：素材確認画面（←→でページ切替、Vで戻る）
- 検証用：1／2＝1Pへ攻撃+1／+10、9／0＝2Pへ攻撃+10／+1

## 確認していただきたい点

- 発射中・上詰め中・B入れ替え中・不成立後の操作制限の感触（時間はすべてテスト用初期値）
- 役宣言の流れ（役名 → 1ラインずつ消去 → 攻撃・相殺）、役成立光の見え方と点滅の同期
- 危険猶予（3秒）と敗北、先取制の試合進行、CPU 3段階の強さ
- ゲームパッドの割当と操作感（自動検証ではゲームパッド実機を使っていません）
- 暫定で決めている扱い（ゲーム中の F1 に一覧があります）
