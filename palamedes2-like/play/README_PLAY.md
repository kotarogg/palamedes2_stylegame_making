# パラメデス２風 第1版統合候補 v1.0.0-rc1（2026-10-20）起動手順・操作説明

メインメニュー、オプション、MODE1（シングル：ひたすら／ステージクリア、CPU対戦、2P対戦）、MODE2（シングル、CPU対戦、2P対戦）、
採用グラフィック v2.3、BGM・効果音・ボイスを統合した版です。

## 必要なもの

- Windows 10／11 の PC
- ブラウザ：Microsoft Edge または Google Chrome の最新版（Firefox でも動く想定。自動検証は Chromium で実施）
- Node.js 18 以上（LTS 推奨）：https://nodejs.org/ （ゲームの起動に使う簡易サーバー用。開発ツールの導入やビルドは不要）

## 起動（Windows）

1. このフォルダ一式を PC に保存する（共有ドライブからはフォルダごとダウンロード → ZIP を右クリック「すべて展開」）
2. 展開したフォルダの `start-windows.bat` をダブルクリック
   - 黒いウィンドウが開き、少しして既定のブラウザで `http://127.0.0.1:8080/` が開きます
   - 「WindowsによってPCが保護されました」と出た場合は「詳細情報」→「実行」
   - ブラウザが自動で開かない場合は、黒いウィンドウに表示された URL を手で開いてください
3. メインメニューが表示されたら、キーボードかゲームパッドで操作します（最初の操作で音が出るようになります）
4. 終了：ブラウザのタブを閉じ、黒いウィンドウを閉じる（または Ctrl+C）

### うまく動かないとき

| 症状 | 対処 |
|---|---|
| `index.html` をダブルクリックすると真っ黒・エラー | 直接開く方法（file://）では素材を読めません。必ず `start-windows.bat` から起動してください |
| 「Node.js was not found」 | Node.js をインストールして、もう一度 `start-windows.bat` を実行 |
| ポート 8080 が使用中 | 自動で 8081〜8090 の空き番号を使います。黒いウィンドウに表示された URL を開いてください |
| 読込中のまま／素材の読込に失敗 | 黒いウィンドウが開いたままか確認し、ブラウザで再読込（F5）。直らなければ Ctrl+F5 |
| 音が出ない | 一度キーを押すかクリックする（ブラウザの自動再生制限）。オプション「音」で音量・ミュートを確認 |
| ゲームパッドが反応しない | ブラウザのタブをクリックしてからボタンを1回押す。オプション「操作」で 1P/2P の入力機器をゲームパッドに変更 |

Node.js が無く Python がある場合は、このフォルダで `python -m http.server 8080 --bind 127.0.0.1` を実行し、`http://127.0.0.1:8080/` を開いても遊べます。

## 操作（初期割当。オプション「操作」で変更可）

| 操作 | 1P キーボード | 2P キーボード | ゲームパッド |
|---|---|---|---|
| 左右移動 | A／D | ←／→ | 十字キー・左スティック |
| 発射 | F | , | A |
| B入れ替え | G | . | B |
| 役宣言 | H | / | X |
| 手動上昇 | W | ↑ | RB |
| 試合をやめる確認 | Esc | Esc | START |

- メニュー：↑↓（十字キー）で選択、Enter／A で決定、Esc／B で戻る、←→ で値の変更
- 試合中の Esc／START は「試合を終了してメニューへ戻りますか？」の確認です。**一時停止ではありません**（確認中もゲームは進みます）
- 結果の後：決定（Enter・発射・A）で次へ。最終結果では「再戦／もう一度」「メニューへ」を選択

## 遊べるモード

| モード | 内容 |
|---|---|
| MODE1 シングル ひたすら | Lv1〜20。消去数で Lv が上がり自然上昇が速くなる（Lv11 で一度ゆっくりに戻る、Lv20 は MAX）。7段のまま猶予が切れるとゲームオーバー |
| MODE1 シングル ステージクリア | 全10ステージ。各ステージの消去ノルマ（成功1個＝1、役の1ライン消去＝6）を達成する |
| MODE1 CPU対戦／2P対戦 | 役・攻撃・相殺ありの対戦。先取本数・自然上昇の速さ・NPCの強さはオプション「対戦」 |
| MODE2 シングル | 6列×7段＝42個を、場のカードへ打ち上げて空にするまでのタイム |
| MODE2 CPU対戦／2P対戦 | 先に自分の盤面を空にした側の勝ち。両者とも出せない時は 3・2・1 の後に場のカードが変わる |

記録（シングルのベスト）と設定は、このブラウザ内に保存されます。

## この版で確認していただきたい点

- BGM・効果音・ボイスの聴感と音量バランス（自動検証では音色・聴感を判定していません）
- ゲームパッド実機での全メニュー操作・割当変更（自動検証は模擬入力のみ）
- 画面倍率（オプション「表示」：自動／1〜4倍）と全画面表示
- 勝敗演出（敗者の落下→勝者）、MODE2 のカウントダウン、ステージ間の引継ぎの感触
