## 2. 実機での確認が必要な事項（ユーザーPC）

1. Windows PC で、共有フォルダからプレイ版を取得・展開し、`start-windows.bat` で起動する。
   全モードを一巡し、最初の操作で音声が有効になることを確かめる。
2. 聴感を確認する。
   - BGM の複数周、ボイス中の BGM 減衰。
   - 音量例外4本（`docs/ASSET_ISSUES_20261020.md` A3）。
   - 長い役名（コタロー role_16 約3.2秒）が途中で切れないか。
   - 効果音の連打・同時発音の聞こえ方。
3. ゲームパッド実機で確認する。
   - 全メニュー、割当変更、結果後の進行、Esc／START の終了確認。
   - 2台接続時の 1P／2P の振り分け。
4. 操作感と演出時間の初期値を確認する。
   - 結果演出：落下700ms、勝者まで200ms。
   - カウントダウンの出入り。
   - NPC の強さ。
5. 表示倍率（自動／1〜4倍）と全画面表示（Edge／Chrome）を確認する。

## 3. 既知問題・注意

- 作業環境では BGM 3本を取得できず、BGM なしで自動検証しました（A1）。プレイ版には同梱しています。
- CPU同士の MODE1 対戦は長期戦になりやすい傾向があります（v0.2.0 から継続）。NPC の反応値は `src/input/cpu.ts` で調整できます。
- 全画面表示は、オプションの操作（キー入力）の中でブラウザへ要求します。全画面設定を保存した場合、次回起動時は最初の操作で全画面化します。ブラウザの設定によっては拒否されることがあります（その場合も通常表示で継続）。
- 演出・音の調整値はすべて設定に分離しています（`src/core/config.ts`、`src/view/presentation.ts`、`src/audio/audioMap.ts`、`src/audio/audioBus.ts` の `DEFAULT_MIX`）。
- GitHub への操作は、作業ブランチ `claude/sweet-meitner-jt0diu` への通常 push だけです。main へのマージ・force push・公開設定の変更はしていません。
