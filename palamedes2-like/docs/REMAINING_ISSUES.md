## 2. 実装者の解釈で進めた点（要確認）

docs/TECH_DECISIONS.md「仕様の解釈」の 1〜11。特に次の3点はゲーム結果に関わるため、早めの確認を推奨します。

1. 盤面構造（列が足場から吊り下がり、上昇は各列の下へ追加、最長列短縮で足場が下がる）
2. 6個宣言で「6個全体の役」を4個部分集合より優先する（翻数が低くても）
3. 同点役の定義（役の種類が異なる最大翻数の候補が複数）

## 3. 既知問題・注意

- 仮素材S1/S2のキャラ画素は大半がα=251〜253（ほぼ不透明）。重なったピースがわずかに透ける。本番素材で完全不透明にするか確認を推奨。
- B入替の暗色ピースは仕様どおり通常ピースの背面を通るため、列が詰まっていると大半が隠れて見えにくい。見せ方（横振れ量 `rotateCurveX` 等）は調整値。
- アニメーション時間はすべてテスト用初期値（`src/core/config.ts`）。原作連番から秒数は確定していない。
- 共有Driveへ ZIP・スクリーンショットPNGを保存できない（コネクタの制約。docs/ENVIRONMENT.md）。ソースとビルド済み実行版はフォルダ構成のまま保存し、PNG/JSON原本はDrive内でコピーした。
- Windows 実機・実キーボードでの確認は未実施。
- GitHub への push は指示書に従い行っていない（ローカルGitにコミットのみ。コンテナ破棄で失われる）。
