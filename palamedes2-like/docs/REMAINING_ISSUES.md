## 3. 既知問題・注意

- 仮素材S1/S2のキャラ画素は大半がα=251〜253（ほぼ不透明）。本番素材は完全不透明で確定済み（今回の仮PNGの変更指示ではない）
- B入替の暗色ピースは仕様どおり通常ピースの背面を通るため、列が詰まっていると大半が隠れて見えにくい
- アニメーション時間・役処理の各フェーズ時間・CPUの反応時間は、すべてテスト用初期値（`src/core/config.ts`、`src/input/cpu.ts`）
- CPU同士の対戦では、互いに消去で耐えるため、上級の自然上昇でも長期戦になりやすい（ルールどおりの挙動。CPUの調整余地あり）
- 共有Driveへ ZIP・スクリーンショットPNGを保存できない（コネクタの制約。docs/ENVIRONMENT.md）
- Windows 実機・実キーボード・ゲームパッド実機での確認は未実施（ゲームパッドはテスト用の模擬入力で検証）
- GitHub への push は行っていない（ローカルGitにコミットのみ。コンテナ破棄で失われる）
