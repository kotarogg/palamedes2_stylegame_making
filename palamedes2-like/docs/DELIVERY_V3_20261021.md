## 2. 保存方法と再取得による確認

| 対象 | 保存方法 | 確認 |
|---|---|---|
| 文字ファイル（HTML・JS・md・bat・sh・mjs） | コネクタで内容を送信 | 保存後に取り直し、SHA-256 が手元と一致（プレイ版15件・ソース91件・検査資料9件） |
| 画像・効果音・ボイス・JSON・OFL | 共有ドライブ内の採用原本（第3版納品・第1版採用物）をサーバー側コピー | 全件のファイルサイズ・名前・保存フォルダが一致。原本は受入時に SHA-256 を照合済み |
| BGM 3本・フォント | 同上（原本のサーバー側コピー） | 10MB超のため取り直し不可。ファイルサイズが原本と一致 |
| プレイ版フォルダ全体 | — | 一覧を取り直し、手元の組立て版と183件すべての名前・サイズが一致、重複・余分なファイルなし |

起動確認は、取り直した文字ファイルが手元と同一であることを確認したうえで、手元の組立て版（同一内容）で実施しました（ブラウザ検査 71/71、配布物検査 5/5。いずれもBGM・フォント未配置を許容するフォールバック検査）。
バイナリ（画像・音声）を共有ドライブから取り直しての起動確認は、取得上限のため実施していません。

## 3. 作業環境の制約による対応

- **一括ZIP**：作成できませんでした。コネクタは1回の呼出しで内容を送る方式で、実用上1ファイル約50KB（画像は約20KB）が上限です。ソースの文字だけのZIP（353KB）も送信できませんでした（実際に失敗した操作：create_file への base64 送信が一度に送れず中止）。代わりに、共有ドライブのフォルダを右クリック→「ダウンロード」で ZIP として取得できます。
- **配布JS**：同じ理由で、未圧縮の単一JS（220KB）を送れなかったため、圧縮・6分割に変更しました（`vite.config.ts`。ゲーム処理は不変、再検査済み）。
- **ソースの画像・音声**：ソースフォルダには送っていません。`public/gfx/assets/` はプレイ版の `gfx/assets/`、`public/assets/audio/{sfx,voice}/` はプレイ版の `assets/audio/{sfx,voice}/` と同一ファイルです（`docs/ASSETS_V3.md` のハッシュ一覧）。BGM・フォントはプレイ版から同じパスへ置きます。`docs/reference/`（第1版の読取り用コピー）・`docs/cpu_balance_v3.json`（143KB の計測生データ）・`docs/screenshots_v3/` も送っていません（GitHub にあります）。
- **スクリーンショット**：共有ドライブには S01〜S26 の各シーン1枚以上（S04 を除く27枚、640×360）を保存しました。約20KBの送信上限のため、10枚は可逆 WebP、17枚は非可逆 WebP（ファイル名末尾 `_qNN` が品質）です。全27枚を取り直して SHA-256 が手元と一致することを確認済みです。全40枚の原寸（2倍解像度PNG）は GitHub の `docs/screenshots_v3/` が正本です。S04 は S03 と同じメニュー画面のため共有ドライブには置いていません。
- **重複ファイル**：並行作業の不具合で一部ファイルが二重に作成されたため、検証済みの1件を残し、もう一方をゴミ箱へ移しました（自分が作成した重複のみ。ゴミ箱から復元可能）。
