## 3. 可読性の自己評価（1倍・640×360）

- **見出し**：「役」（2倍）・「連鎖」「打上」（原寸16px）は1倍でも判読でき、旧来の48×12縮小で潰れていた細線は解消しました。縁取りにより、背景の装飾の上でも読めます
- **役連鎖数**：1桁（34px）は明瞭です。2桁（27px）も読めます。3桁（16px）は小さくなりますが判読可能です
- **打上連鎖数（17px）**：S12 の「1」は斜めの装飾字形のため、17px では「7」に近く見えます（例：「12」が「72」に見えうる）。ヒビが重なると、さらに読みにくくなります。既存字形をそのまま縮めた結果で、配置ではなく字形と高さの問題です（第6章 質問1）
- **SINGLE の「得点倍率」（9px・補助色）**：読めますが淡く、背景の明るい装飾と重なる位置では読みにくくなります。倍率値（17px）は読めます
- **攻撃加算「＋数」（Noto 16px・縁取りなし）**：従来どおりです。背景によってはコントラストが弱めです

## 5. 仕様判断

1. **縁取り**：倍率と同じ幅（「役」2px、他1px）の8方向縁取りを付けています（指示書の「外接36×36」に合わせた実装）
2. **教材の注目枠**：役連鎖は「役」〜役連鎖数（教材はシングル表示のため攻撃加算を含めない）、打上連鎖は「打上」〜打上連鎖数とし、数字の幅上限46に合わせた箱＋1pxとしました
3. **得点倍率の表示条件**：連鎖教材の「攻撃倍率の扱い」（`streakRate: 'attack'`）では、従来どおり得点倍率を描きません
