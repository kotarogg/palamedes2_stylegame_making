## 共有Driveとの取得・保存（v1.0.0-rc1 で再確認した結果）

| 項目 | 結果 |
|---|---|
| 接続手段 | Claude 側の Google Drive コネクタ（認証済み） |
| 仕様・JSON・PNG・効果音・ボイスの取得 | 可。PNG13枚・WAV76本はマニフェスト／測定CSVの SHA-256 と全一致 |
| BGM（12〜16.7MB）の取得 | **不可**。コネクタの取得上限（約10MB）を超える。コンテナから drive.google.com への直接HTTPはプロキシで拒否（403） |
| テキストの保存 | 可。保存後に再取得して SHA-256 一致を確認 |
| PNG・WAV（BGM含む）の保存 | 可。Drive 内のサーバー側コピーで保存し、ファイルサイズが原本と一致することを確認 |
| ZIP の保存 | 一括ZIPはコンテナ内で作成・展開検証のみ。コネクタはファイル内容をツール呼出しの本文で渡す方式のため、数MBのZIPは実用上送れない。プレイ版は Drive 上にフォルダ構成のまま保存し、ユーザーは Drive の「ダウンロード」でフォルダを ZIP として取得できる |

資格情報・トークンは記録していません。
ローカル設定 `.claude/settings.local.json`（リポジトリ管理外）で、コネクタ出力の上限 `MAX_MCP_OUTPUT_TOKENS` を下げています。
