## フォント制作・実装への申し送り

採用ファイルNotoSansJP-VF.ttf、Noto Sans JP Version2.004を基準に、16px・weight400でFreeType/Pillowによりラスタライズ、閾値100で白1色へ整理しました。字形の拡大縮小はしていません。ASCIIにはフォント内のOpenType `hwid` 字形を使用して、送り幅8pxを確保しています。日本語は送り16px、本文行送り22pxです。

「撃」は車の内側の空白、「続」は売の横画間と冖内側、「鎖」は金偏の横画間を手で指定したピクセル編集で開きました。「|」は元の18px高の線を14pxへ整理し、セル外クリップに頼らず収めています。編集位置はフォントJSONに記録しています。全313字を一覧で目視確認し、役名16種・数字・記号・最長本文・戻る案内も原寸で確認しました。

フォントセルは16×16の白マスク、原点は左上(0,0)、offsetは(0,0)。ASCIIでも切り出しは16×16、送りのみ8pxです。ASCIIの描画ピクセルは8px以内へ収め、次の文字へはみ出しません。U+0020は透明セル・送り8pxを定義しています。

表示色は本文#fff1d6、見出し#f2b950、補助#a5c5c5。戻る案内だけ表示側で#0b1f35の1px縁取りを付けます。輪郭はフォント画像へ焼き込んでいません。収録外文字は既存Noto Sans JPへフォールバックし、欠字コードポイントを検出・報告する想定です。今回フォールバック処理の実装はしていません。

元TTFは重複納品していません。フォント由来の白マスクはOFLを継承し、ライセンス本文と出典・著作権を同梱しています。クレジットには「Noto Sans JP／原権利者はlicenses/font_attribution.txt／SIL Open Font License1.1」を記載できる形です。原本の権利表記を省略しないでください。

## 操作アイコンと強調枠

操作アイコンは24×24×6、順番は左移動・右移動・列循環・打ち上げ・役宣言・せり上がりです。ボタン名や文字は含めていません。列循環は縦3段と上→下の折り返し、打ち上げは単ピース→場、役宣言は複数ピース→星の合図、せり上がりは下段補充＋上方向で区別しました。

強調枠は24×24、上下左右4pxの9-slice、中央16×16透明です。4隅の短い角印を固定し、辺と中央は透明のまま伸長できます。24pxピースを囲むなら32×32、32pxピースなら40×40へ9-sliceして使えます。全周が光る成立光とは区別し、点滅位相の画像は追加していません。2素材合計6色で共通8色以内です。
