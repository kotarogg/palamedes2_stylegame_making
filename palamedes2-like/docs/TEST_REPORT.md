- BGM 3本（各12〜16.7MB）は作業環境へ取得できません。コネクタの上限は10MBで、drive.google.com への直接通信はプロキシで拒否（403）されます。

- 中間評価では、企画側が正式BGM入りのコピーで次を確認済みです。
