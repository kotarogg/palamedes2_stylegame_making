# 第3版 仕様差分（v3.0.0-rc1、2026-10-21 統合実装開始指示の反映）

基準：v1.0.0-rc1（コミット 5e1dcbf）。優先順位は「本指示 → 採用素材と各イベント表 → 既存確定仕様・数値原本 → 現行実装」。
「PM指定初期値」は実装値として採用し、下表の設定へ置いた（デバッグ時に変更可能）。攻撃倍率・翻数・相殺効率・CPU難度は変更していない。

表示（第10・11章、`src/view/stockLayout.ts`・`gameView.ts`、設定 `DEFAULT_STOCK_VIEW`・`DEFAULT_PLAY_VIEW`）：

- 大アイコン＝5ライン（16×16）、小＝1ライン（8×8、左上→右上→左下→右下の2×2）。各群とも大を先に。
- 上の群＝処理中ブロック（予約高さを終了まで維持、残ったアイコンだけを点滅枠で囲う。240ms）、下の群＝nextPending（予約領域の下に固定、ブロック終了で120ms上詰め）。群を混ぜない。
- 列の位置：1P x=20、2P x=604、上端 y=148（2026-10-22 修正R1。旧 y=228 では開始時の予約29＋待機24で下端410となり画面外。予約1〜29×残量×待機の全組合せで画面内を単体検査で確認）。
- 相殺：XD顔＋小爆発 4コマ×40ms の残像（減算は即時）。相殺SEは1回。ピンチ破棄：120msでフェードして消える（XD・SEなし）。
- 消失演出（2026-10-22 追加修正R5）：表示専用で有効なストックではない（上限29・相殺・消化に含めない）。相殺ごとに独立した対象・開始・終了（160ms）を持ち、位置は相殺の時点で「相殺後に残った待機群の下」に確定する（待機群の上端からの相対位置。後の受信・相殺で末尾へ配置し直さない。上詰めでは待機群と一緒に動く）。通常ストックより前面に描き、同じ位置の演出は発生順（新しいほど前面）に重ねる。
- 消失演出の打切り（R5）：①ラウンド終了・ラウンド差し替え（新ラウンド・新試合・メニュー復帰）で全件、②そのプレイヤーのブロック開始で全件（待機群が現ブロックへ切り替わる。有効な待機だけで現ブロック表示を開始し、数量は減らし直さない）、③ブロック終了時に待機群が残っていれば、そのプレイヤーのピンチ破棄の残像（上詰めする待機群と重なるため）。他のプレイヤーの演出は消さない。打ち切った演出は復活しない。
- 待機ライン数の数字（R5）：nextPending（消失対象を含めない）を、待機群の上端の高さで列の外側（1P は左、2P は右）に表示。受信・相殺で即時更新。待機0かつ相殺演出なしのときは表示しない。
- 接着：新しい段は画面下から120msで飛来→120ms・最大2pxで揺れ（6列同時）。接着音 sfx_attack_row は1ライン1回（120ms遅延＝接着時）。
- 上昇音 se_field_rise：攻撃の実適用1段につき上昇開始（適用tick）で1回（2026-10-22 修正R2。発音元は attackRow に統一し、攻撃の rise では鳴らさない）。自然・手動の上昇は rise から1回。
- 役ピースの白反射：3コマ×50ms、列ごと30ms遅延（左→右、同列同時）。

## 2. 音（第12章）

- 打ち上げ成功 se_launch_success_01〜05（連続取得数、6以上は05。MODE2は01）、役宣言 se_role_declare_01〜05（役連鎖数）。2系統は独立。置き換えた旧音（sfx_piece_success・sfx_role_success・sfx_chain・旧 sfx_field_rise）は収録・再生しない。
- 相殺 sfx_counter（新、SHA 606d6ec8…）は1回の相殺につき1回。
- キャラクター選択の決定ボイス（select）は決定時に1回。専用の select チャンネルで鳴らし、1P・2Pの声は重なってよい。選択→試合開始の一括停止・READY では止めず終端まで鳴らす。取消・メニュー復帰・再戦では止める（2026-10-22 修正R3）。
- READY／GO：シングル＝コタロー、CPU対戦＝相手、2P対戦＝ラウンドごとに両者から等確率（ゲームと別の乱数）。READY と GO は同じ話者。
- 攻撃ピンチ猶予の開始・継続中は、既存の危険警告音を流用（補完。ピンチ破棄そのものは無音）。

## 3. 役名表示（第13章 B4・B5、`src/view/presentation.ts`・設定 `DEFAULT_ROLE_NAME`）

- 代表役＝先頭ロゴ。代表役ボイスは先頭ロゴの表示開始と同時（役名表示の予定側で鳴らす）。
- 先頭の保持＝max(600ms, ボイスのファイル尺)、＋150ms、以降の後続ロゴ各600ms。
- 後続ロゴ中の新宣言は後続を中止して即開始、先頭保持中の新宣言は最新1件だけを待たせる。結果で全消去。ゲーム処理の時間は延長しない。

## 4. 結果演出（第14章、設定 `DEFAULT_PRESENTATION`）

- B1：ラウンドごとに入力機器・CPU・キューを初期化。
- 勝敗確定→勝利数＋1→WIN/LOSE＋結果SE→敗者 lose_fall（4×160＝640ms）＋敗北ボイス→モーション後に最終姿勢で落下700ms（開始で se_character_fall）→200ms→勝者モーション＋勝利ボイス、同時にネコタローがクラッカー1回（勝者側へ。1P勝利は左右反転）＋se_result_cracker。敗者ボイスの終了は待たない。
- 引分け：両者 lose モーション、落下・声・SE・クラッカーなし。シングル成功はクラッカーあり、ゲームオーバーはなし。

## 5. キャラクター・シーン（第15・16章）

- キャラとプレイヤー番号を分離。モーションシート：コタロー S1、アカネ S2、ずん子 S13。入替ポーズ attack_01。
- 2P対戦：キャラクター選択（コタロー／アカネ／東北ずん子、初期 1P コタロー・2P アカネ、相手の位置を飛ばして循環、同キャラ不可、決定済みは固定、戻るは自分の決定だけ取消、両者未決定の戻るで前のメニュー、同フレーム入力は 1P→2P）。両者決定でただちに開始（2026-10-22 修正R3で固定900ms待機を撤廃。決定ボイスの終了を待たない。同じフレームの残りの入力は試合へ渡さない）。
- CPU対戦：1P はコタロー、相手はアカネから。勝ち＝次の相手へ／同じ相手と再戦／メニュー、負け・引分け＝同じ相手に再挑戦／メニュー。「次の相手へ」だけがアカネ↔ずん子を進める。メインメニューへ戻るとアカネ。保存しない。各試合の開始で勝利数0。
- 2P対戦の終了：同じキャラで再戦／キャラ選択へ／メニューへ。
- タイトル（タイトル背景・ロゴ・コタロー＋ネコタローの画像のみ）→最初の決定でメインメニュー。最初の入力で音声の有効化を試み、その入力は次の画面へ渡さない。BGM はメニュー曲（自動再生を強制しない、タイトル→メニューで再始動しない）。
- メインメニュー：MODE1／MODE2／オプション／遊び方。オプション：音／操作／対戦／表示／クレジット／設定初期化／戻る。
- クレジット：credits_text.json（編集可能）。左右でページ、上下でリンク選択、決定で外部ブラウザ、ページ位置を維持。B/Esc で戻る。
- 画面と scene_correspondence.json S01〜S26 の対応：e2e のスクリーンショット名（S01_title … S26_confirm_*）。

## 6. 表示倍率（第17章 B6、`src/view/scale.ts`・`main.ts`）

- 固定N倍：描画バッファ 640N×360N、CSS (640N/DPR)×(360N/DPR)。論理座標640×360で描き、バッファ倍率で拡大（補間なし）。
- 「収まる最大」は別の選択肢。収まらない固定倍率は選べず「選択不可」と表示（固定倍率は ×1〜×4。2026-10-22 修正R4）。
- 現在の固定倍率が収まらなくなったら「収まる最大」へ明示的に切り替え、設定を書き換えて通知。スクロールなし。
- 1倍（実画素）も収まらない時だけ緊急縮小し通知。devicePixelRatio の変化を検知して選び直す。
