# 技術選定と設計上の解釈（2026-10-18、v1.0.0-rc1 で更新）

## 技術選定

**TypeScript ＋ Vite ＋ Canvas 2D（独自の小さな描画層）＋ Vitest**。Phaser は採用しなかった。

理由：
1. 仕様の中心は「ロジックの論理時刻で成否・順序が確定し、描画は補間するだけ」（到達順・1P優先・帰還下降の固定時間・FPS非依存）。Phaser の Scene/Tween はフレーム駆動で、論理時刻からの補間と二重管理になりやすい。
2. 描画要素は矩形切出しとZ順の重ね合わせのみで、物理・シーン管理は不要。Canvas 2D で十分かつ依存が最小（実行時依存0）。
3. 640×360の整数倍拡大・`imageSmoothingEnabled=false`・CSS `image-rendering: pixelated` でドットを滲ませない制御が直接できる。
4. ロジックを Node 上で高速に自動テストできる（DOM不要）。

Vite はビルド・開発サーバー、Vitest は同じ設定でテスト。ブラウザ確認は playwright-core（実行時依存ではない）。

## 構造

- `src/core`：固定ステップ（60tick/秒）のゲームロジック。入力はtick単位のコマンド、出力は状態とイベント列。描画へ依存しない。
- `src/view`：イベント列を読み、論理時刻＋補間率で座標を計算して描画（ロジックへ書き戻さない）。
- `src/input`：1P/2P別系統の `Controller`。CPU は同じ窓口に後から追加できる。
- 時間値は `src/core/config.ts` に集約（テスト用初期値）。ゲーム結果に関わる未確定ルールは設定値として埋めていない。

- 1ラウンド＝`Game`、先取制の試合＝`Match`（勝敗表示 → 決定入力 → 新しい `Game`）。

1tick内の処理順（v0.2.0）：
基準到達（到達tick昇順、同一tickは1P優先）→ 帰還完了 → 役処理フェーズの進行（攻撃送信は双方の相殺計算後にまとめて反映）
→ 入力（1P→2P、移動終了時の保持入力を先に処理）→ 役連鎖タイマー → 自然上昇・危険猶予 → 攻撃波 → 敗北判定（同一tickの両者敗北は引分け）。
到達を入力より先に処理するため、成功到達と同じtickの入力は上詰めの操作制限を受けます。

## v1.0.0-rc1（第1版統合候補）で追加した構造

技術選定は変えていません（別エンジンへの移行なし）。v0.2.0 のロジックと tick 内の処理順を維持し、差分を追加しました。

- **画面遷移**：`src/app.ts` の `App` がシーン（メニュー／オプション／遊び方／試合）を切り替えます。メニュー入力はキーボードとゲームパッドを `MenuInput` で同じ操作列に変換します。試合中は各プレイヤーの機器を `Controller` が直接読みます。
- **試合とシングル**：対戦は `Match`（先取制）、シングルは `SingleSession`（ステージ進行・持越し）が `Game`／`Mode2Game` を作り直して進めます。どちらも同じ `AnyGame` 窓口で描画・音・CPU へ渡します。
- **MODE1 シングル**：`Game` の `single` オプションで動きます（相手盤面なし・送信なし）。ノルマ、Lv、周期、得点倍率は `mode1_balance_v1.json` を `balance.ts` で読みます。数値をコードに直書きしていません。
- **MODE2**：`Mode2Game` は独立したルールクラスです。打ち上げの成功判定は MODE1 と同じ関数を使います。役・B・上昇・攻撃のコードを持たないため、MODE1 の機能が誤って働くことはありません。
- **段階攻撃**：波の開始時に段数を予約し（`wave`）、200ms ごとに1段を適用します。適用前に毎回6段の容量を確認します。適用禁止中（役処理中）は進めず、再開後の段は直前の段から200ms以上空けます。
- **音**：ロジックはイベント列を出すだけです。`SoundDirector` がイベントを1回ずつ読んで鳴らします。開始・結果の音は `Staging` が tick を時計にして1回だけ鳴らします。ファイル名は `audioMap.ts` だけに書いています。音の有無・長さでゲームの判定は変わりません（READY の表示時間だけは担当ボイスの長さを使いますが、開始tickは試合開始時に確定します）。
- **表示**：描画は `GameView` に集約し、モードごとに枠・情報欄を切り替えます。倍率の数字は S12 の数字・×・小数点を合成し、タイマーは S11 の塗りを縦に切り取って表示します。
- **配布**：ビルド済み `dist/` に依存なしの `serve.mjs`（ポート自動切替・ブラウザ起動）と起動用バッチを加えます。ユーザーPCで Node.js の開発環境やビルドは不要です。
