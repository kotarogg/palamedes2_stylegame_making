## 2. 作業環境の制約（納品検査が未実施の範囲）

- BGM 3本（12〜17MB）と採用フォント NotoSansJP-VF.ttf（9,590,732 bytes）は、共有ドライブから作業環境へ取得できない（コネクタの取得上限約10MB。GitHub等の直接取得も遮断）。
  - そのため、BGM・フォントを含む**納品検査（`npm run e2e`／`check-release.mjs` 既定）はこの環境では実行できていない**。フォールバック検査はBGM・フォントの未配置だけを許容する開発検査で、納品の合格判定には使っていない。
  - プレイ版の BGM・フォントは共有ドライブ内の原本をサーバー側コピーで同梱し、ファイルサイズの一致を確認した（内容のバイト比較・ブラウザでの実デコードは未実施）。
- 画面のスクリーンショットは、採用フォントと同じ書体（Google Fonts の Noto Sans JP 可変、SIL OFL 1.1）の **Fontsource 分割版を検査時だけ代用**して撮影した。配布物には含めていない。採用ファイルとの字形・字送りの差は確認していない。
- 操作はすべて模擬入力（キーボードイベント・模擬ゲームパッド）。**実機・実パッド・聴感は未検証**。全画面はヘッドレス Chromium での要求・解除のみ確認。

## 4. 発注者側での確認手順（推奨）

1. 共有ドライブのプレイ版フォルダをダウンロード・展開し、`start-windows.bat` を実行（README_PLAY.md）。
2. タイトル→メインメニューで、BGM が鳴ること、画面上部にフォントの警告が出ないことを確認。
3. MODE1 CPU対戦：攻撃を受けた時の左右のストック表示（上＝処理中、下＝待機）、段の飛来と接着音、7段時のピンチ、勝敗演出（落下→勝者＋クラッカー）、勝利後の「次の相手へ」でずん子になること。
4. MODE1 2P対戦：キャラクター選択（同じキャラを選べない、各自の取消）、3キャラのモーション・ボイス。
5. オプション「表示」：DPI 125％／150％の PC で各倍率の表示と「選択不可」、全画面。
6. ゲームパッド実機：タイトル〜メニュー〜キャラ選択〜試合〜結果までパッドだけで操作。
7. 聴感：段階SE（成功・宣言）、役名とボイスの同期、音量バランス、クリップの有無。
8. （任意）開発版での人間プレイ計測：ソースで `npm install`→`npm run dev`、対戦後に F8 で計測JSONを保存。
