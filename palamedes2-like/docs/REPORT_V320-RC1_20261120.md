### 4.1 既存 E2E の不合格 2 件（基準版と同一・本改修と無関係）
既存 E2E は公開版に含まれない検証用フックを使うため、通常ビルドで実行し、同じ手順で基準 a70b851 のビルドも実行して比較しました。合否は 117 項目すべて基準と一致しています。

1. 「拡大時にドットを滲ませない(image-rendering)」：`index.html` は `pixelated` の後に `crisp-edges` を指定しています（a70b851 から変更なし）。本検証環境の Chromium は新しい版で `crisp-edges` を解釈するため、計算値が `crisp-edges` になり期待値 `pixelated` と不一致になります。どちらも最近傍補間の指定で、画面写真でもドットの滲みは見られません。仕様変更を避けるため修正していません。
2. 「コンソールエラー/警告なし」：ブラウザが自動で要求する `/favicon.ico` の 404 です（ゲームは参照していません）。配信サーバー側の記録で 404 はこの1種のみであることを確認しました。旧スマホ版・基準版でも同じです。アイコン追加は未承認の変更にあたるため行っていません。必要であれば次版で対応可能です。

E2E の実行環境：プロジェクトの playwright-core が想定する Chromium の版が環境に無いため、環境既定の Chromium を起動時に指定して実行しました（スクリプト本体は変更していません）。

## 5. 動作確認（PC・スマートフォン）

すべて Chromium（ヘッドレス）での確認です。スマホは端末エミュレーション（タッチ・`pointer: coarse`・画面サイズ・UA）で、タッチは CDP の実タッチ入力（ブラウザがポインターイベントを生成）を使っています。**実機・実ゲームパッドでの確認と聴感確認は行っていません。**

### 5.1 PC（1280×720）
- 起動、`build-info.json`（3.2.0 / v3.2.0-rc.1 / 1c57b85）、採用フォントの読込を確認。
- スマホ用操作画面を表示しないこと、`__p2like` が公開版に無いことを確認。
- キーボード操作を確認：タイトル → メニュー → MODE1 シングル（ひたすら）開始 → 移動・打上げ → Esc。
- HTTP 4xx/5xx なし（favicon を除く。4.1 参照）、ページエラーなし。
- `?touch=1` でスマホ用画面を確認できること。
- ゲーム内容の詳細（各モード・CPU・演出・音声 117 本のデコード等）は既存 E2E（通常ビルド・同一コード）で確認。

## 6. 承認済み製品との差異確認
- `git diff a70b851 1c57b85 -- src` の変更は `src/app.ts`・`src/main.ts`・`src/measure/build.ts`（スマホ用フック・公開ビルド判定・版表示）と新規 `src/mobile/` のみです。core・CPU・入力（PC）・描画・音声のコードは変更していません。
- 単体テスト：a70b851 の 570 件はすべて合格しています（M1EASY-02 の固定 seed・CPU 試験を含む）。
- 既存 E2E：117＋30 項目の合否が基準版と一致しています。
- PC では、スマホ用フックはすべて `mobile` 判定で分岐し、無効時は従来どおり動作します。ただし `mobile.css` は PC でも読み込まれます。セレクターはスマホ用要素（`body.mobile`・`#mobile-*`）に限定されています。

## 7. 未確認事項・制限
- 実機（iPhone/Android・PC 実ブラウザ各種）、実ゲームパッド、聴感の確認はしていません。検証はすべて Chromium のエミュレーションによるものです。Safari（WebKit）の挙動は未確認です。
- Cloudflare Pages での実配信は確認していません（一般公開禁止のため）。最大ファイルは BGM の WAV（約 16.8MB）で、Cloudflare Pages の 1 ファイル上限（25MiB）以内です（上限値は公開情報に基づく認識で、本作業では再確認していません）。
- 全画面ボタン・画面回転・iOS のホーム画面追加時の挙動は未確認です（旧スマホ版から変更なし）。
- `/favicon.ico` は未同梱です（4.1）。
