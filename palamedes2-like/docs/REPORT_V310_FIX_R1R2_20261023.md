## 2. R1：開始前待機中の GO 誤表示

**原因**

- `gameView.collectCenter` は、READY の条件に「待機中でない」ことを加えていました。
- そのため待機中（tick 0）は READY の条件から外れ、次の GO の条件（`t < playStartTick + GO 時間`）が成立していました。
- 結果として、待機中に S9/show_go_A〜C が描かれていました。

**修正**

- 開始の見出しを `startBanner(t)`（`src/view/gameView.ts`）へまとめました。
- 開始前待機中は READY・GO のどちらも返しません。待機後は既存どおり READY→GO です。
- 時計・入力・CPU・音声の待機処理（`GameScene.updateHold`）は変更していません。

**確認**

| 検査 | 内容 | 結果 |
|---|---|---|
| 単体 | 待機中は見出しなし。待機後に READY → GO。新ラウンド（`reset`）でも待機中は見出しなし | 合格 |
| ブラウザ（画素照合） | 開始前待機中は描画のたびに画面を調べ、READY・GO の全位相（A/B/C）が描かれていないこと、tick 0 のままであることを確認。待機後に READY が描かれることも確認 | 合格 |

ブラウザ検査で調べた場面と描画回数：

- 最初の開始：61描画
- 新ラウンド（勝敗の後、決定で次のラウンド）：60描画
- 再戦（「同じキャラで再戦」と同じ処理）：61描画

既存の開始前待機の検査（tick 0・READY 前・待機中の発射を持ち越さない）も合格しています。
