## 9. 実装判断と理由

ゲームルール、確率、優先順位、演出順は変更していません。以下はいずれも、ルール外の実装上の判断です。

1. **ピンチボイスを必須読込にしました（114 → 117本）。**
   - 理由：3本とも納品・採用済みのためです。任意読込のままでは、欠落しても検査で検出できません。
   - 配布物検査と e2e で、取得・デコードを必須にしています。
2. **ピンチボイスの優先度は最低（5）で、どのチャンネルでも声が鳴っていれば鳴らさず捨てます。**
   - 対象には、遅延開始で予約済みの声も含みます。
   - 指示に挙がっている READY／GO、役名・代替、選択、結果に加えて、**役不成立ボイスと、もう一方のプレイヤーのピンチボイス**も「先行する声」として扱います。
   - 理由：低優先度の声が先行する声を中断せず、重ねもしないためです。
   - 逆に、ピンチボイスの再生中に役不成立ボイスが始まった場合は、既存の優先順位（不成立 10 ＞ ピンチ 5）に従い、ピンチボイスを止めます。
3. **代表ボイス（役名・代替）が「予定されている」間も、ピンチボイスを鳴らしません。**
   - 予定とは、表示待ちの宣言がある場合と、同じフレームでまだ取り込んでいない宣言がある場合です。
   - 理由：鳴らした直後に役名ボイスで切られる重なりを作らないためです。
4. **抽選はピンチ到達（`pinchWarn` の start）につき1回です。**
   - 外れた場合も、競合で鳴らせなかった場合も、抽選済みとして数えます。
   - 先に抽選し、当たった場合に競合を判定します。このため、競合した到達はその回の機会を使い切ります（「再生できなかったから後で再抽選」はしません）。
   - 解除（`end`）・新ラウンド（`reset`）で抽選状態を戻します。
   - 自然上昇と攻撃ピンチは、コア側で合算した1つの連続ピンチとして start／end が出ます。原因が移っても上限は戻りません。
5. **ピンチ解除ではピンチボイスを止めません。** 結果移行（`stopPlaySounds`）、新ラウンド・再戦・メニュー復帰（`stopEffects`）では止めます。
6. **テスト用に、抽選乱数を注入できるようにしました**（`DirectorOptions.rng`）。製品の動作は従来どおり、seed 付きの乱数です。

代替攻撃ボイスと役名ボイスの排他（宣言ごとに1回の抽選、前回が代替なら役名、先頭ロゴと同時に1本）は、既存の実装が仕様を満たしていたため、変更していません。

役名表示の先頭ロゴの保持は、既存仕様 `max(600ms, 代表ボイスの実尺) + 150ms` のままです。このため、表示時間は新しい尺に自動で追従します。

- 例：アカネの代替攻撃ボイスでは、保持が 600ms から約1153ms になります。
- これは表示側の予定だけで、ゲームの進行は待たせません。

固定長で音声を切る箇所はありませんでした。終端の判定には、ファイルの実尺（デコード後の長さ、またはヘッダ）を使っています。

## 12. 未確認事項・PM判断が必要な事項

以下のタイミングは、仕様どおりの動作から計算した値です（事実＝計算値。聞こえ方は未確認）。

1. **キャラ選択ボイスと READY ボイスの重なり**
   - 選択ボイスは遷移で止めない仕様です。READY は「最初の描画＋開始前待機 1000ms」の後に鳴ります。
   - このため、アカネで約0.41秒、ずん子で約0.33秒重なる見込みです。
   - 選択ボイスは、2P 対戦では最後に決定した人の分、CPU 戦では 1P の分が対象です。
   - コタローの選択ボイス（1.94秒、既存）は、従来から約0.9秒重なっていました。
   - 待機時間は延ばさず、演出順も変えていません。
   - 推奨：聴感で確認し、問題があれば READY 側の扱いを PM が判断してください。
2. **ピンチボイスとカウントダウン SE の重なり**
   - ピンチボイスは到達時（danger SE と同時）に始まり、「3」のカウントダウン SE は 1000ms 後です。
   - 末尾が重なる長さ：コタロー約0.53秒、アカネ約0.31秒、ずん子約0.17秒。
   - SE なので、優先度の規則（声同士）の対象外です。聴感の確認が必要です。
3. **勝利ボイスの途中停止**
   - 結果の決定入力は、勝者演出の開始 300ms 後から受け付けます。
   - すぐ決定すると、次ラウンド・メニュー復帰の既存規則（前の演出の声を持ち越さない）で、勝利ボイスが途中で止まります。
   - 対象：アカネ1.23秒、ずん子1.37秒（コタロー1.58秒は既存）。
   - 固定タイマーではなく、人の操作によるものです。既存規則のため変更していません。
4. **敗北ボイスと勝者演出の間隔**
   - 敗北ボイスと勝利ボイスは重ならないことを確認しました。
   - ただし、勝者演出開始までの余白は、ずん子で約20ms、アカネで約82msと短くなっています。
5. **役名表示の保持時間**
   - 代替攻撃ボイスでは、先頭ロゴの保持が約1.1〜1.15秒（＋150ms）に延びます。既存の同期仕様どおりです。
   - 連続宣言時の表示待ちも、その分長くなります。
   - あわせて、延びた表示の見え方（テンポ）も、聴感と同時に確認してください。アカネの role_fail・pinch は、テンポの重点確認対象です（サウンド側の申し送り）。
6. **確認できていない環境**：実機、実パッド、正式素材（BGM・採用フォント）でのブラウザ検査、聴感。

## 13. ビルド・起動手順の変更

ありません。必須音源の本数だけが変わりました（114 → 117本、ボイス72 → 75本）。配布物検査と e2e は、新しい本数で判定します。
