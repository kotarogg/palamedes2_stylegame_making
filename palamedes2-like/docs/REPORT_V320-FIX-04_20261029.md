## 4. 発見した事項（バグ・仕様の相互作用）

1. **役処理の延長で相殺が間に合わない場面が増える**（仕様どおりの相互作用。バグではありません）
   - 再現：待機1ラインを受けた直後に、4翻の役を盤面4段で宣言します
   - 役処理は導入1200＋消去4回×320ms＝約2.5秒です。受攻撃ブロックは受信2000ms後に開始し、待機分が処理中ブロックへ移ります
   - そのため攻撃処理の時点で相殺対象（次ブロック待機分）が0になります（旧時間では約2.0秒で間に合っていた例）
   - 既存試験4件は、消去1ラインの盤面へ直して意図（相殺の処理順）を検証し直しました
   - 計測（第5章）でも、初級の相殺数は旧 13.3→新 3.9／試合（両者計）に減っています
   - 「受攻撃の400ms周期を遅くしない」「相殺対象は次ブロック待機分のみ」に従い、ゲーム側は変更していません（第7章 Q3）
2. MODE2 のミス帰還も、共通設定 descendMs により1600ms になります（第6章「人間・CPU・本編…共通適用」と解釈）。MODE2 の計測値にはこの影響が含まれます
3. 検査の不具合（修正済み）：オプション「デモ再生」の検査で、パッドの決定とキーの Enter が同時に入ると、Enter がデモの終了操作になる競合がありました。製品の動作ではなく検査の手順の問題のため、検査を修正しました

新たな製品バグは見つかっていません。
