## 4. 実装上の判断と理由（仕様変更なし）

1. **教材のシングル設定は、Lv の進行だけを止めました。**
   - 本体のバランス値から機械的に作っており、数値の転記はしていません（`lessonBalance`）
   - 理由：4/4/6 の教材は消去数56に達し、そのままでは途中で Lv が上がって音と自然上昇の周期が変わるためです。設計書の「レベル進行に必要な消去数は別管理」に合わせました
   - 得点は内部で計算されますが、表示も保存もしません
2. **教材の連続出しの倍率は、攻撃倍率で表示しました。**
   - 既存のシングル表示は得点倍率（3回で×1.5）です
   - 設計書は「7個目/13個目は倍率1.25/1.5」「攻撃倍率アップ」を求めているため、教材だけ攻撃倍率にしました
   - 値は本体の現在値（`currentStreakPercent`）を使い、パネルに第二の状態は持たせていません
   - SINGLE デモは本編どおり得点倍率のままです
3. **教材は READY／GO を出さず、入力受付の開始から始めます。**
   - 教材の間はゲームの時間を止めます。説明を読ませる「停止」と「実演」を分けるためです
   - SINGLE と対戦のデモは、本編どおり READY／GO から始めます
4. **章の切り替えのたびに暗転（600/300/600ms）を挟みます。**
   - 理由：教材を作り直すたびに盤面が切り替わることを明示するためです
   - 4/4/6 の教材の中では盤面を作り直しません
   - タイトル → 放置デモでも、タイトル側で暗転してから始めます。暗転中に入力があれば取り消します
5. **ピンチの教材の盤面は、こちらで固定しました。**
   - 設計書に指定がないため、4段の固定盤面とし、最初の自然上昇だけ開始から4000ms にしています
   - 周期そのもの（Lv1 7000ms）と猶予（4000ms、1秒後から3/2/1）は本体の値です
   - 理由：手動上昇で7段にした後、自然上昇まで約5秒の空白ができるのを避けるためです
   - 基本操作の教材で最後に上昇する1行も、指定がないため教材の乱数（固定 seed）で作っています
6. **役一覧の見出しは区分（数字役／属性役／複合役）にしました。**
   - 役名は既存の役名ロゴ（S7）を左フィールドに表示します
   - 理由：「スーパーストレートフラッシュ」（14字）などが、見出しの10字・16px・縮小なしの条件に収まらないためです
   - 成立条件・「消去○ライン」・「基本攻撃○ライン」は、本体の役判定（`evaluateSubset`）と攻撃計算（`computeAttack`、倍率1・連鎖加算なし）から表示します
   - 手役に実例を置き、成立光は本体の判定で光ります
7. **MODE2 の「役・攻撃・入替・上昇なし」（12字）は2行に分けました**（「役・攻撃・」／「入替・上昇なし」）。本文1行10字・縮小なし・語の途中で改行しない、という条件に合わせるためです。
8. **遊び方の目次には、6番目に「操作一覧」を追加しました。**
   - 設計書の5項目に加えたもので、従来の文章頁（キー・パッドの割当説明）を残すためです
   - 旧い「自然3秒・攻撃2秒」の記述は、「4秒の猶予（1秒後から3・2・1）」へ更新しました
   - 文章頁は既存フォントのままです
9. **字体を使い分けました。**
   - オプションの「遊び方」「デモ再生」の行：既存の行と同じ字体（Noto Sans JP）。同じ一覧の中で字体が混ざらないようにするためです
   - 遊び方の目次（新しい画面）：既存のメニュー項目の枠に、共通ビットマップフォントで描いています
10. **タイトルの「しばらくするとデモが始まります」は、中央下（文字の上端 y340）に置きました。** 設計書に位置の指定がないため、タイトルの既存部品と重ならない位置を選んでいます。
11. **対戦デモの seed は 92 にしました。** seed 1〜120 を本体の処理で試した結果、次の条件をすべて満たしたためです。
    - 両者が攻撃を送信している
    - 攻撃段の適用（34回）と相殺（10回）が見える
    - 60秒以内（約58秒）に決着し、勝敗演出まで見せられる

    未決着の場合は、60秒＋区切り待ち（役処理・飛行中ピースがない状態）最大5秒で次へ進みます。
12. **非アクティブの判定には、タブ非表示・ウィンドウのフォーカス喪失の両方を使います。**
    - 放置デモでは、進行と音を止めます（BGM 停止）。復帰するとタイトルへ戻ります
    - 本編の動作は変えていません
13. **パッドの終了判定は、新しい操作だけを数えます。**
    - 開始時に押していたボタンは、一度離すまで数えません
    - スティックは、0.7以上へ倒した瞬間だけ数えます（0.4未満へ戻すまで再判定しません）
    - キーボードは、リピート（押しっぱなし）を数えません
    - 終了に使った入力は消費し、タイトルの決定へは渡しません
14. **未解除の無音と素材の欠落を区別して記録します。**
    - 音声の有効化前の再生要求は、`locked` として記録します
    - 素材の欠落は、従来どおり `skipped: 'missing'` です
    - 有効化前でもデモは進みます。画面上部の既存の案内（最初の操作で音が出ます）は、そのまま表示します
