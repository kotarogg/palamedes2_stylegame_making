# ゲーム基本仕様書
2026-10-18 受領資料反映／内容改訂 v0.2（既存ファイル名・ID維持）


正本参照：00_game_spec_integrated_v1.0.md。今回ユーザーが持ち帰った統合仕様を反映。受領資料自身が未確定とする事項は未確定のまま維持する。

## 画面・対象
論理解像度640×360。左右に各6列×7段・1マス32×32の盤面。1P盤面左上(64,128)、2P(384,128)、各192×224。基準ピースは両者共通。CPU対戦とローカル2人対戦を第1版対象とする。TypeScript＋Phaserは候補。受領仕様では、具体的な採用はプログラマーが構成と照合して決定する。既存実装があるという意味ではない。ひたすら/QUEST等は将来対象で、第1版優先はCPU/ローカル対戦。

## ピースと発射
数字1〜6×属性♠♦♣♥＝24種。同じ種の複数存在を許可。生成は原則24種類均等。MATCH初期盤面は6列×下側3段＝18個。選択列の最上段を共通基準ピースへ打ち上げる。
成功は「数字一致」「数字が隣接」「属性一致」のいずれか。数字の隣接は環状で1と6も隣接する。成功判定は発射時でなく到達時。

`success = (n == base.n) OR (abs(n-base.n) in {1,5}) OR (suit == base.suit)`

先に到達したピースから判定し、成功時に基準を即更新する。後発は更新後の基準で判定。同一到達フレームは1P優先。例えば基準1♠へ1Pの2♥と2Pの4♥が同一フレーム到達すると、1P成功で2♥に更新後、2Pも属性一致で成功する。元基準のまま両者判定してはならない。

発射位置は予約空白として保持し、発射時には列を詰めない。成功到達時に基準更新・ストック追加・予約解除を行い、残りを上詰めTWEEN。失敗は元列へ帰還する。空列・操作競合の扱いは未確定項目を参照。

## 失敗帰還
基準から高速の山なり曲線で元列Xへ戻り、その後ゆっくり垂直下降する。帰還先の予約空白は盤面上昇に伴い移動する。下降中は最新帰還先Yを再計算し、下降時間は盤面高さ変化によらず一定。完了時に最終座標へSNAP。帰還待ち列の打ち上げ・B入れ替えは禁止。他列は操作可能。

## B列入れ替え
最上段を最下段へ循環させ、残りを上へ詰める。論理順序変更と描画TWEENを区別する。最上段ピースは暗くし、通常ピースの背面を通過。押下時、キャラを攻撃4枚中1枚へ即FRAME切替し、短時間で元へ戻す。キャラ座標は変えない。専用の派手なエフェクトは不要。

## 役ストックと宣言
24×24を左詰め6個。7個目で最古の左端を破棄し、即詰め直す。取得順そのものではなく部分集合で役を判定する。
- 4個：4個を対象に判定。
- 5個：5通りの4個部分集合から最強を採択。
- 6個：成立する最強6個役を優先。なければ15通りの4個部分集合から最強を採択。
- 数字役と属性役は同じ部分集合で判定。別々の部分集合の最強結果を合成しない。
- 宣言後は採択した部分集合だけでなくストック全体を消費。

属性役のみの成立も有効。複数属性役は最強の1種だけ採用し、数字役と加算する。複合表示名を別役として二重加算しない。成立しない宣言と同点役の選択は未確定。役名一覧を強さ順位として扱わない。

## 攻撃と相殺
攻撃ストック上限29ライン。10ライン大アイコン最大2個、1ライン小アイコン最大9個。小は左列5個まで縦積みし、6個目以降を右列へ配置。旧記載の左4・右5は訂正。内部ストックも29に飽和する。
最大3ラインずつ波状適用。波の間隔約2秒は暫定。攻撃で7段目まで押し込まず、入りきらない量は保持。被攻撃者が役宣言演出中ならWAITする。
相殺力は通常攻撃力の2倍。余剰相殺力は攻撃へ転用しない。通常攻撃力の計算式・端数・一部相殺時の送信扱いは未確定のため実装しない。

## 表示・操作制限
役名16種類を各3フレーム色替えループで表示。役名ロゴは上下文字を強く重ねた一体型。1P(120,34)、2P(360,34)を指定表示位置とし、アンカー解釈は画面表に明記。役宣言側は演出中操作禁止、相手は操作を継続可能。キャラ・役ストックへの役名重なりを許可。
キャラ左右移動はTWEEN。足元Yは盤面最高列の上端に合わせ、全列共通。列ごとの高さに追従して上下しない。

## 受領した統合仕様から確認できた役条件
以下は受領資料の第6〜7章に明記された条件。翻数は攻撃量への換算式とは別に扱う。

| 数字役 | 条件 | 翻 |
|---|---|---:|
| フォーカード | 同数字4個 | 1 |
| ニコニコ | 異なる数字のペア2組 | 1 |
| ストレート | 通常4連番（1234/3456） | 1 |
| ハイストレート | 2345 | 2 |
| フルカード | 同数字6個 | 3 |
| ニコニコニコ | 異なる数字各3個の2組 | 3 |
| スーパーストレート | 123456 | 3 |

属性役は同色統一1翻（赤♦♥、黒♠♣、4/6個とも）、4属性を全て含むオールマーク2翻、同属性統一フラッシュ3翻。発射の1↔6隣接を役の循環連番へ転用しない。
ストレートフラッシュは1+3=4翻、ハイは2+3=5翻、スーパーは3+3=6翻。R08〜R11の個数別命名・R16表示名は受領資料で暫定とされている。既存PNGの役名は維持し、判定と表示名を分離する。

## 上昇・連鎖・勝敗
自然/手動上昇は32pxのTWEEN。手動で7段を超えない。発射中も自然上昇は原則進行し、宣言側の停止対象演出中は自然上昇を停止する。攻撃追加はSNAPで6段まで。
失敗で連続成功間隔タイマーを更新・リセットしない。宣言後も連続取得状態を不要に初期化しない。自然/手動上昇そのものは役連鎖を断ち切らない。役連鎖ボーナスへ取得速度倍率を重ね掛けしない。
連続取得約2秒、倍率1〜2個×1/3〜4個×1.5/5〜6個×2/7以上×2.5、役連鎖約8秒とmin(chainCount-1,4)は受領資料でも復元/暫定値。攻撃倍率と得点倍率を区別し、正式な適用境界は未確定として管理する。
7段は危険。約3秒の猶予後の8段到達で敗北する案は、開始/解除/再発動時点を含め未確定。何勝先取・引分け・再戦入力も未確定。

## 残る仕様決定
翻数→消去量→攻撃量、消去範囲/方向/確定時刻、相殺の端数/送信順、同点役、無役宣言、発射制限、空列、同時イベント全順序は受領仕様第19章に明記された未確定事項。原資料不足という扱いを解除し、要決定として課題台帳に集約する。
