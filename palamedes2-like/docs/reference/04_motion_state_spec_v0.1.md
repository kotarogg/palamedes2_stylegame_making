# ゲーム動作・アニメーション仕様
2026-10-18 受領資料反映／内容改訂v0.2


## 論理・描画の分離
ゲームロジックは盤面・予約・基準・ストック・イベント時刻を保持し、描画側はその結果を時間補間する。TWEENの途中座標を成否判定へ使わない。瞬間的論理更新と画面上の瞬間移動は別概念。

| 分類 | 対象 | 原則 |
|---|---|---|
| TWEEN | キャラ横移動、打上げ直線、成功後上詰め、B循環、自然/手動上昇、失敗山なり・下降 | 座標補間。打上げ時間は距離/列にかかわらず同一 |
| SNAP | 攻撃行追加、ストック左詰め、基準変更、帰還最終補正 | 描画も瞬間更新 |
| FRAME | 待機・歩行・打上げ・攻撃・勝利・敗北、役名色替え、効果 | マニフェストにあるフレームを切替 |
| WAIT | 宣言中の操作禁止、被攻撃側演出中の波待ち、帰還待ち列の禁止操作 | 局所的に待機。相手・他列まで一律停止しない |

## 発射ピースの状態
READY → OUTBOUND → ARRIVAL。
ARRIVALで成功なら基準SNAP更新・ストックSNAP追加・列上詰めTWEENへ進み終了。
失敗なら BOUNCE_ARC → VERTICAL_RETURN → FINAL_SNAP → 終了。予約は帰還完了まで保持。
予約セルは画面Yの数値だけではなく列・論理セルに対応する識別子で管理する。失敗確定前の発射中にも予約が必要だが、発射時は列を詰めない。帰還待ち列の発射/Bは禁止。同一プレイヤーの複数発射可否などは受領資料でも未確定。独断で許可しない。

## 失敗下降の技術提案
下降開始時刻t0と終了時刻t1=t0+returnMsを固定。u=clamp((now-t0)/returnMs,0,1)、目標Y(now)を毎描画再取得し、Y=lerp(startY,targetY(now),ease(u))。Xは元列中心に固定。u=1で現在の予約位置へSNAPして解放する。
目標移動時にt0を更新しない。毎フレーム現在位置から残時間不明の追従lerpを繰り返さない。上昇・攻撃SNAP・ライン消去が重なった場合も予約セルの変換を経由する。消去が予約セルそのものに干渉する仕様は未確定のため要確認。

## B循環とキャラ
押下時に論理列の順序変更イベントを作成、最上段は暗色の背面経路で最下段へTWEEN。他ピースも新順序へTWEEN。キャラは座標固定、攻撃12〜15枠のうち1枚を短く表示し復帰する。採用枠・表示msはテスト設定とし、4枚フル再生を必須にしない。
キャラ横移動中の次入力、B再入力、上昇との合成は未確認。入力バッファ/拒否/打切りなどを無断で正式ルール化しない。

## 共通基準の競合
両プレイヤーの到達イベントを同じ処理系へ集約。到達フレーム昇順、同一フレームなら1Pを先に処理。成功で即基準更新し、その更新後に次のイベントを判定する。表示用コールバックの呼出順・可変FPSに依存させない。固定ステップや論理時刻は実装方針として推奨。
同一プレイヤーの複数到達、到達と宣言/消去/上昇/敗北が同一フレームの場合の全順序は受領仕様でも未確定。技術的なソート順をゲーム仕様の確定と混同しない。

## 役演出・攻撃波
役宣言中は宣言者の入力を禁止し、相手入力は継続。被攻撃者の役演出終了後に保留波を再評価する。適用可能量は最大3かつ7段目へ到達しない範囲。未適用量を保持。
波の開始時刻、WAIT中のタイマ残量、同時相殺/波の優先順位、消去の確定時点は要確認。約2000msの波間隔だけを根拠に推定しない。自然/手動上昇は各32pxのTWEEN、手動7段超過は禁止。宣言側の自然上昇は演出中停止する。

## 描画順
最新統合仕様第13章を優先。Zは背景0、固定枠10、B暗色30、通常40、基準/ストック/UI50、役背面光55、キャラ/猫60、役前面光65、役名70、帰還80、打上げ90、接触95、勝敗/COUNTER100、READY/GO110。
前版の「役名が帰還/打上げより前」は訂正。役名・キャラ＜帰還＜打上げ。B暗色＜通常も確定。
役ストック50＜背面光55＜キャラ60＜前面光65を受領資料どおり採用。背面/前面の名称だけを根拠に数値の不整合とは扱わない。

## 可変設定と未確定ルール
キャラ移動ms、打上げms、山なりms/高さ、帰還ms、上詰めms、B移動ms/暗度、各FRAME fps、B一瞬ポーズms、ロゴ表示ms/倍率は調整用設定として分離可能。値は未設定であり、原作連番から推定秒数を確定しない。
翻数/消去/攻撃式・勝敗境界・同時イベント順はゲーム結果を変える。未確定ルールを軽微な設定として補完してはならない。

## 必須検証項目
1. 24×24種の到達成功判定を独立期待値で照合し、1↔6隣接と属性一致を含める。
2. 到達前の基準変更、同一フレーム1P優先、更新後基準で2P判定。
3. 帰還下降中に自然上昇・攻撃SNAP・許可された消去を発生させ、所要時間不変・最終座標一致・予約二重消費なし。
4. 帰還列だけ操作禁止で他列と相手入力は機能する。
5. ストック7個目破棄、5個の5部分集合・6個の15部分集合、同一部分集合で数字/属性判定、宣言で全消費。
6. 攻撃29上限と大2/小9の全0〜29表示、左5→右4配置、最大3波、容量不足保持、演出中WAIT。
7. B循環は暗色背面経由で、キャラのX/Yは不変。移動TWEENとポーズ表示を独立確認。
8. 役名16×3フレーム、全シート切出し、可変描画FPSでロジック結果が変わらない。
未確定仕様に依存する期待値は、仕様確定後に追加する。現時点でテストを実行した意味ではない。
